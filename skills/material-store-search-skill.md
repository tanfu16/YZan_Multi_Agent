# Material Store Search Skill

## 1. Skill 作用

这个 skill 用于在用户需要购买装修材料时，调用高德地图 MCP 搜索附近的线下购买地址。

它解决的问题是：
- 用户已经知道想买什么材料
- 但不知道附近去哪里买
- 系统需要返回最近 3 个可参考的线下门店地址

当前对应的外部能力：
- 高德地图 MCP

当前项目中的实现承载：
- `AmapMcpMaterialSearchClient`

---

## 2. 触发条件

当用户明确表达以下意图之一时，应该触发这个 skill：

- 想找某种装修材料在哪里买
- 想知道附近哪里有卖某种材料
- 想获取线下购买地址
- 想查询最近 3 个门店

典型用户表达：
- “附近哪里可以买防滑地砖？”
- “帮我找上海卖乳胶漆的地方”
- “我想知道哪里能买定制柜板材”

不应该触发的情况：
- 用户只是在问装修方案，不需要采购信息
- 用户是在问线上商品推荐，而不是线下门店
- 用户还没有明确材料关键词

---

## 3. 所需输入

至少需要以下输入：

- `location`
  - 城市名或区域位置
  - 例如：`上海`、`杭州`、`浦东`

- `materialKeyword`
  - 材料关键词
  - 例如：`防滑地砖`、`乳胶漆`、`定制柜板材`

如果用户没有明确提供位置：
- 可以优先询问城市
- 或使用系统默认城市

---

## 4. 调用的 MCP 能力

本 skill 对应：
- 高德地图 MCP

推荐优先使用的能力：
- 关键词搜索
- 附近门店搜索

当前项目中由以下客户端承接：
- `MaterialSearchClient`
- `AmapMcpMaterialSearchClient`

---

## 5. 输出格式要求

输出必须尽量结构化，至少包含以下字段：

- `materialKeyword`
- `storeName`
- `address`
- `distance`

建议一次返回 3 条结果。

返回示例：

```json
[
  {
    "materialKeyword": "防滑地砖",
    "storeName": "某某建材市场",
    "address": "上海市浦东新区某某路 100 号",
    "distance": "1.2km"
  },
  {
    "materialKeyword": "防滑地砖",
    "storeName": "某某瓷砖中心",
    "address": "上海市浦东新区某某大道 66 号",
    "distance": "2.8km"
  }
]
```

---

## 6. 降级策略

如果高德 MCP 调用失败：
- 不要伪造门店结果
- 直接明确告知“当前无法获取线下门店信息”

如果只返回部分结果：
- 可以返回不足 3 条
- 但需要如实说明

如果用户未提供位置：
- 先提示需要城市或地区信息

---

## 7. 使用说明

这个 skill 的目标不是提供装修建议，而是：
- 给已经明确材料需求的用户
- 增加一层线下采购辅助信息

它更适合放在：
- 方案生成之后
- 或用户主动追问“在哪里买”时

不建议默认每次都调用。

---
